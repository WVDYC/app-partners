Информация о конфиденциальности

Эта страница объясняет, как работает форма обращения на сайте ТОО «APP PARTNERS».

Форма обращения

Вы можете указать имя, компанию, телефон или e-mail, направление и описание задачи. Форма подготавливает письмо в вашем почтовом приложении. Сам сайт не отправляет и не сохраняет содержимое формы на сервере. Обращение поступит компании только после отправки письма вами.

Для чего нужны данные

Данные в отправленном письме предназначены для ответа на ваш запрос, обсуждения задачи и подготовки предложения. Указывайте только информацию, необходимую для обращения.

Внешние сервисы

Сайт размещён на GitHub Pages. Шрифты загружаются через Google Fonts. Эти сервисы обрабатывают технические сведения, необходимые для загрузки сайта и ресурсов, согласно своим правилам. Аналитические и рекламные счётчики на сайте не установлены. Ссылка на карту открывает Google Maps только при переходе по ней.
