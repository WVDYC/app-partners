# APP PARTNERS

Корпоративный сайт ТОО «APP PARTNERS»: разработка программного обеспечения, ИТ-оборудование, внедрение и поддержка.

**Сайт:** https://wvdyc.github.io/app-partners/

## Структура

- `index.html` — главная: направления, подход, отрасли, компания и контакты.
- `services/` — семь отдельных страниц услуг.
- `privacy.html` — информация о конфиденциальности.
- `assets/` — стили, JavaScript и векторная графика.
- `build.py` — генератор HTML-страниц на Python 3, без сторонних зависимостей.

## Локальный запуск

```sh
python3 -m http.server 4173
```

Открыть http://localhost:4173.

После изменений в `build.py` пересоздать страницы:

```sh
python3 build.py
```

Стили и JavaScript редактируются напрямую в `assets/`.

## Публикация

GitHub Pages: ветка `main`, каталог `/` (Deploy from a branch). Сборка и установка пакетов не требуются. Файл `.nojekyll` отключает обработку Jekyll.

## Обращения

Форма готовит письмо на `Sale@apppartners.kz` в почтовом приложении посетителя. Посетитель должен отправить письмо сам. Сайт не хранит данные формы и не имитирует отправку на сервер. Предусмотрено копирование текста обращения.

Кейсы, отзывы, партнёрские статусы и неподтверждённые показатели не добавлены. Телефон, WhatsApp и график работы можно добавить после получения данных. Векторный знак воссоздан по предоставленному референсу, название написано полностью — APP PARTNERS.

Демонстрационная версия содержит `noindex, nofollow`. Перед запуском на основном домене уберите этот meta-тег в `build.py` и пересоберите страницы.
